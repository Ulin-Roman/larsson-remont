# Larsson — ремонт квартир

Многостраничный сайт для посетителей из Москвы и Московской области. GitHub Pages публикует содержимое корня ветки `main`.

## Обновление

Отредактируйте контакты в `site.json`, тексты услуг в `services.json`, список интерьеров в `heroes.json` или проекты в `works.json`. Фотографии находятся в `assets/`. После изменений выполните `node src/build.mjs` и включите в коммит сгенерированные HTML и карту сайта. Для проверки запустите в корне `python -m http.server 3000`.

## Реклама

Для каждой услуги есть посадочная страница с собственным URL. Сайт переносит UTM-метки и `yclid` во внутренние ссылки и в калькулятор на действующем лендинге. Форма на странице сметы открывает подготовленное сообщение в WhatsApp. Клиент отправляет его в приложении самостоятельно.

Для подключения назначенного счётчика укажите его номер в `site.json` в поле `metrikaId` и повторите сборку. Идентификаторы JavaScript-целей для настройки в Яндекс Метрике перечислены ниже.

| Цель | Действие посетителя |
| --- | --- |
| `phone_click` | Нажал на номер телефона |
| `telegram_click` | Открыл Telegram |
| `email_click` | Нажал на почтовый адрес |
| `estimate_click` | Перешёл к расчёту стоимости |
| `estimate_form_click` | Открыл калькулятор на рекламном лендинге |
| `whatsapp_estimate_open` | Перешёл в WhatsApp с заполненными параметрами |

Подтверждённое обращение учитывается по факту звонка или получения сообщения. При переносе сайта на другой домен обновите `publicUrl` и пересоберите страницы.
