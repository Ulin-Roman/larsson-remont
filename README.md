# Larsson — ремонт квартир

Многостраничный сайт для посетителей из Москвы и Московской области. GitHub Pages публикует содержимое корня ветки `main`.

## Обновление

Отредактируйте контакты в `site.json`, тексты услуг в `services.json`, завершённые объекты в `projects.json`, сравнения этапов в `works.json` и сведения о команде в `team.json`. Ценовые ориентиры и подтверждённые условия находятся в `content-verified.json`. Фотографии находятся в `assets/`. После изменений выполните `node src/build.mjs` и включите в коммит сгенерированные HTML и карту сайта. Для проверки запустите в корне `python -m http.server 3000`.

## Реклама

Для каждой услуги и каждого проекта есть собственная страница. Сайт сохраняет UTM-метки и `yclid` при переходах и передаёт их в действующий калькулятор Larsson на Marquiz. Квиз загружается при открытии окна расчёта. Его отправка и обработка обращений настроены в существующем аккаунте компании.

Расчёт на странице показывает предварительный ориентир по опубликованным тарифам для квартиры 60 м². Это пропорциональная оценка стоимости работ. Материалы и комплектация рассчитываются отдельно. Параметры локального расчёта не предзаполняют Marquiz.

Для подключения назначенного счётчика укажите его номер в `site.json` в поле `metrikaId` и повторите сборку. Идентификаторы JavaScript-целей для настройки в Яндекс Метрике перечислены ниже.

| Цель | Действие посетителя |
| --- | --- |
| `phone_click` | Нажал на номер телефона |
| `telegram_click` | Открыл Telegram |
| `email_click` | Нажал на почтовый адрес |
| `calculator_click` | Перешёл к предварительному расчёту на странице |
| `estimate_click` | Нажал на кнопку подробного расчёта |
| `quote_open` | Открыл действующий квиз Larsson |

Конверсию отправки квиза следует настроить в Marquiz по подтверждённому событию отправки. Сайт учитывает открытие окна отдельно. При переносе сайта на другой домен обновите `publicUrl` и пересоберите страницы.
